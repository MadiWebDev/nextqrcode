## Decisions (user: NO questions — coordinator decided, recorded here)

- **Scope**: 100 new working features (new static routes) + 1000 new blog articles (Batch70–Batch169, 10 per file).
- **Features**: each is a real client-side tool (generators use the `qrcode` lib; bulk tools use `jszip`; PDF via `jspdf`). No stubs, TODOs, lorem, or fake results. Calculators show their formulas; trainers/quizzes give explanations.
- **Articles**: each via `art()`, ≥450 words (aim 550+), exactly 3 unique FAQs, ≥6 unique internal links (mix of existing routes + the 100 new feature routes in this plan), category from the 4 allowed values, unique slug/title, `publishedAt` spread across 2027 (3 per day). No fabricated statistics, percentages, dates, study claims, or provider claims.
- **Wiring (coordinator, at the end)**: article batches into `src/lib/pages/index.ts`; new routes into `src/app/sitemap.ts` (`toolPaths` / `generatorPaths`); registry entries in `src/data/page-registry.ts` if the pattern fits. Homepage featured grid (`FEATURED_TOOL_META` + i18n `home.tools.cards`, 15 featured) is intentionally NOT expanded — it is index-coupled across 14 locale files; new tools are reachable via sitemap, `/sitemap-page`, article links, and breadcrumbs.
- **Links**: articles may link to any of the 100 new routes below (guaranteed built) plus existing routes. New routes are auto-discovered by the audit `collectStaticRoutes` scan of `src/app/**/page.tsx`.
- **Batch ownership**: feature group N (20 routes) → one agent; topic batch N (100 topics) → one agent writing Batch70+10(N-1) … Batch79+10(N-1). Agents touch ONLY their own files; coordinator owns shared files (index.ts, sitemap.ts, registry) and final verification.
- **Verification**: analyze-batches (0 deficiencies, 0 dup slugs), `npm run content:audit` (blog total 1581, all pass), `npm run typecheck` (exit 0), `npm run build` (completes). No gate is claimed green unless it ran.
- **No ranking guarantees**: “top at Google in 2027” is a goal, not a promise. Quality gates + genuine usefulness are the strategy.
